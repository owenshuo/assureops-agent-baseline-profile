# Security Policy

Do not report production secrets, internal infrastructure details, customer
data, or exploitable vulnerabilities in a public issue. Contact the repository
owner privately through the security-reporting channel configured on the
hosting platform.

This profile executes a pinned sibling AssureOps checkout. The collector
requires an exact clean commit, uses a temporary output directory, and does not
accept an arbitrary command. Review any change to the pinned source, executable
method registry, or subprocess boundary as security-sensitive.
